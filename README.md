# Джефф — питомец для Forsaken World

Два комплекта одной модели: тестовая замена Боки и ресурсы отдельного нового питомца. Здесь размещены распакованные файлы для просмотра и проверки администратором. Релиз не создавался.

| Вариант | Для чего нужен | Модель |
|---|---|---|
| [1 — замена Боки](<Вариант 1 — замена Боки>) | Проверка Джеффа вместо существующего пингвина | `models\npcs\宠物\宠物_企鹅\宠物_企鹅.ecm` |
| [2 — отдельный Джефф](<Вариант 2 — отдельный Джефф>) | Добавление нового питомца с собственными ID | `models\npcs\宠物\jeff_fw\jeff_fw.ecm` |

**Для добавления нового питомца нужен вариант 2.** Установка ресурсов сама по себе не создаёт нового питомца: администратор должен связать новые записи пути, питомца и предмета призыва в данных своей версии клиента и сервера. В репозитории нет готовых изменённых игровых таблиц или назначенных числовых ID.

## Состав каждого варианта

- **22 ресурса модели:** ECM, SMD, SKI, BON, одна DDS и 17 STCK.
- **12 звуков WAV:** моно, 44 100 Гц, 16 бит.
- Скелет: **240 костей**; сетка: **17 999 треугольников**.
- ECM: **75 составных действий**; постоянные эффекты донора отключены (`CoGfxNum: 0`).
- Всего в двух вариантах: **68 игровых ресурсов**, с отдельными копиями для удобства установки.

Ни один файл из варианта 1 не требуется для установки варианта 2. Звуковые ресурсы обоих вариантов одинаковы и используют общую папку `Monster\pets\jeff_fw` в `sfx.pck`.

## Текущее поведение

- Направление модели исправлено; глаза, лапы и UV подготовлены. На медальоне — логотип игры.
- Оба отдыха/AFK: `104771_1047_SpitOut`, скорость 75%.
- Действие бафа `技能攻击2`: `104721_WaterBomb`, скорость 75%.
- Озвучка **варианта 8**: ходьба и бег используют одобренный «там-там» длиной около **2,02 секунды**, скорость записи 70%, тон сохранён.
- Звук движения запускается как цикл: `Once: 1`, `IsLoop: 1`, `FadeOut: 150` мс.
- Обычное стояние — без нового звука. Озвучка атак, бафов, отдыха и реакций на урон сохранена.

## Установка в тестовый клиент

1. Выбрать **один** вариант. Оба варианта одновременно для проверки отдельного нового питомца устанавливать не следует.
2. Добавить содержимое его `models.pck.files` в `models.pck`, а содержимое `sfx.pck.files` — в `sfx.pck`, сохраняя пути относительно этих папок.
3. Папки с суффиксом `.pck.files` не должны становиться дополнительным уровнем внутри архивов.
4. Просмотрщик FW 4.3.19 умеет устанавливать обе папки выбранного варианта вместе и делать общий откат. Перед установкой сохранить исходные ресурсы и закрыть игру и лаунчер.
5. Для отдельного питомца выполнить [настройку новых записей](<Вариант 2 — отдельный Джефф/Админу — добавление Джеффа.md>), сохранив оригинального Боки.

## Что уже проверено

Пользователь подтвердил работу геометрии, текстур и движений в игре на тестовой замене Боки. Перенос модели в отдельные пути проверен чтением файлов и разрешением ссылок. Последняя запись ходьбы/бега одобрена пользователем для тестирования; её поведение в игре пока не подтверждено.

При подготовке репозитория игровые ресурсы сверены побайтно с готовыми комплектами. Файлы WAV и ссылки звуков проверены, ZIP прежних комплектов сохранён локально. Новые бинарные таблицы клиента и сервера не создавались.

Перед вводом отдельного Джеффа проверить:

- непрерывность звука движения и его остановку при остановке питомца, атаке и бафе;
- повторный призыв, все движения и нужные стадии качества;
- наличие общих GFX/ATT/SFX в клиенте администратора;
- новые ID, иконки, предмет призыва, характеристики и отображение у другого игрока.

## Проверка скачанных файлов

Из корня репозитория запустить Python 3.9 или новее:

```text
python "Проверить комплект.py"
```

Скрипт проверяет SHA-256 и размеры всех 68 ресурсов, формат WAV, наличие звуков, на которые ссылаются ECM, и отсутствие лишних ресурсов внутри папок архивов. Он ничего не устанавливает и не изменяет.

## Исходная модель

Джефф — персонаж Marvel Rivals. Для подготовки использована скачанная модель из набора `Jeff the Land Shark (Marvel Rivals)` от `nekopixil`. Здесь размещены адаптированные игровые ресурсы FW, а не исходные FBX/PSK/PSA или полный клиент игры.
