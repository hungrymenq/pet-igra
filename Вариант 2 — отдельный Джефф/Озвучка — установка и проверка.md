# Джефф: комплект с одобренной озвучкой

В комплекте 22 файла модели и 12 новых звуков. Выбор сохранён в «Одобренная озвучка.json».

1. Содержимое `models.pck.files` добавить в архив `models.pck`, сохранив вложенные пути.
2. Содержимое `sfx.pck.files` добавить в архив `sfx.pck`, сохранив вложенные пути. Не переносить звуки в models.pck.
3. Проверить в игре отдых, баф, атаки, бег, урон и смерть. Если инструмент установки принимает только один архив, установить обе папки по очереди.

Громкость и задержки взяты из вашего выбора. Реакции на урон обрезаны по концу движения. Обычное стояние теперь без нового звука. Для ходьбы и бега установлен одобренный вариант 8: первоначальный «там-там» продлён до 2,02 секунды, скорость 70%, тон сохранён. Это один фрагмент исходной записи от 4,13 до 5,55 секунды, без склейки повторов. В ECM выставлены Once: 1 и IsLoop: 1 по примеру игровых питомцев; FadeOut: 150 мс. Запись больше не обрезается до длины короткой анимации бега. Остановку цикла при смене действия следует проверить в игре. Звуки пространственные: расстояние слышимости 5–15 метров по настройке игрового примера.

Боевая стойка оставлена без нового звука. Плавание и точки крепления не менялись. Общие игровые эффекты и их прежние звуки сохранены. Новая озвучка проверена по структуре файлов; её запуск в игре ещё нужно проверить.

Это отдельный новый питомец. Для регистрации админ должен назначить свободные ID и настроить запись питомца и яйца, как описано в «Админу — добавление Джеффа.md». Путь модели: `models\npcs\宠物\jeff_fw\jeff_fw.ecm`. Бинарные таблицы игры здесь не изменены.


Версия озвучки 8. В просмотрщике 4.3.19 выберите общую папку этого комплекта: models.pck.files и sfx.pck.files установятся вместе. Для обновления предыдущего патча общий откат не требуется: новые файлы заменят старые. Старая WAV стояния может остаться в архиве, но ECM больше к ней не обращается.
